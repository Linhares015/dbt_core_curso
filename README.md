# Northstar Analytics — dbt Core Capstone

A fully local dbt Core + DuckDB reference project for CURSO-001.

## Prerequisites

- Python 3.13+
- `uv` (recommended) or a Python virtual-environment tool

## Reproduce from a clean checkout

```bash
uv sync
.venv/bin/dbt seed --profiles-dir .
.venv/bin/dbt build --profiles-dir .
.venv/bin/dbt docs generate --profiles-dir .
```

## Expected result

- Four synthetic raw datasets are loaded as seeds.
- Staging, intermediate and mart models build successfully.
- Generic and custom data tests pass.
- `target/index.html` and `target/manifest.json` are generated by `dbt docs generate`.

## Project structure

- `seeds/`: synthetic educational e-commerce data.
- `models/staging/`: cleaned source-aligned models.
- `models/intermediate/`: reusable business logic.
- `models/marts/`: analytics-ready fact, dimension and marts.
- `tests/`: custom data-quality tests.
- `macros/`: reusable SQL/Jinja helpers.

The database file and generated dbt artifacts are intentionally ignored by Git.
